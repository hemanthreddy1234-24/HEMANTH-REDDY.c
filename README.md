# RentalHub - Bikes, Cars & Electronics Rental

## Five files
1. index.html
2. style.css
3. script.js
4. README.md
5. LICENSE

## Included rental categories
### Bikes
Hero, KTM, MT-15, R15, RX 100

### Cars
Tata, BMW, Maruti, Thar, Swift, Kia

### Electronics
Canon, Sony and Nikon category cameras, DJI/category drones, JBL and Sony category speakers

## Features
- Category filters
- Click a product to open details
- Quantity selection
- Rental cart
- Automatic price calculation
- Start/end rental dates
- Customer details
- Payment selection: PhonePe, Google Pay and Paytm
- Demo UPI field
- Booking confirmation

## Run
Extract the ZIP and open index.html in a modern browser.

## Important
This project contains a FRONT-END DEMO payment flow. It does not process real payments and does not connect to PhonePe, Google Pay or Paytm. For real payments, use the official payment gateway APIs/SDKs through a secure backend such as Java Spring Boot. Never collect or store UPI PINs, card PINs, CVVs or passwords in this website.
